# Sonsuz Çay Bekletici v2.0

## Resmi Olmayan, Abartılı, Gereksiz Ama Çalışan Protokol

Bu repository, çay demleme işlemini bilimsel olarak kanıtlanmış hiçbir şeye dayanmayan, aşırı ciddiyetle ele alan bir protokol sunmaktadır.

### Neden Var?

Çünkü:
- Çay demlenirken beklemek sıkıcıdır.
- Bu kod o sıkıcılığı abartarak eğlenceli hale getirir.
- GitHub'da yer işgal etmek bazen sanattır.

### Nasıl Kullanılır?

```bash
python cay_demle.py
```

Kod çalışır. Beklersiniz. Biter. Çay içersiniz (veya içmezsiniz, protokol o kısmı kapsamaz).

### Özellikler

- Rastgele bekleme süreleri (sürpriz faktörü yüksek)
- Dramatik mesajlar
- Gerçek zamanlı ilerleme çubuğu (sort of)
- KeyboardInterrupt ile iptal imkanı (tarih bunu yazacak)
